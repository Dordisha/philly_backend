PHILLY SCAN 1.1.0-preview.6 (9)

This preview adds native iOS notification code. Keep your previous working project
as a backup. Use the FULL source folder for this preview, not just the lib folder.

Fresh checkout, in the mobile folder:
  flutter pub get
  flutter build ios --config-only --simulator --debug --dart-define=APP_ENV=test --dart-define=PRO_PREVIEW=true
  cd ios
  pod install
  open Runner.xcworkspace

Choose Runner and an iPhone simulator, then Run. Do not open the workspace before
preparing the generated configuration and Pods on your Mac.

If a compiled simulator artifact is available, unzip it to Runner.app and drag it
onto a running iPhone Simulator. It is not a Mac app; do not double-click it.

Debug permits test access without payment. Profile/release stay locked.
This source adds the update gate and notification plumbing; the existing live backend
has not been deployed with it. No mandatory update is active and no push has been sent.
Actual APNs testing needs Apple capability/provisioning, server secrets and a signed
physical iPhone build. See ../docs/updates-and-announcements.md for setup.
The approved green/gold logo is recorded; existing app icon assets are unchanged.
Schools, crime and AI answers are still not connected.
