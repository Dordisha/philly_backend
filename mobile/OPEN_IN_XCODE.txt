PHILLY SCAN 1.1.0-preview.5 (8) — SIMULATOR SOURCE

If you already have a working local mobile project:
1. Make a backup of that working folder.
2. Replace ONLY its lib folder and pubspec.yaml with these versions.
3. In that working mobile folder, run flutter pub get.
4. Open ios/Runner.xcworkspace, choose Runner and an iPhone simulator, then Run.
Keep the working ios folder, local generated configuration and Pods intact.
No new Flutter plugin dependencies have been added.

For a fresh checkout, first run in the mobile folder:
  flutter pub get
  flutter build ios --config-only --simulator --debug --dart-define=APP_ENV=test --dart-define=PRO_PREVIEW=true
  cd ios
  pod install
  open Runner.xcworkspace

Do not open the workspace before preparing a fresh checkout. Generated.xcconfig
and CocoaPods support files must be generated on your Mac.
